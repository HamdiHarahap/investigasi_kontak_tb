# Panduan Investigasi Kontak TB

Website edukasi penginputan data investigasi kontak tuberkulosis — React (Vite), Tailwind CSS, AOS, dan Lucide React.

## Menjalankan

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Konten utama ada di `src/data/data.js`, disusun mengikuti rancangan panduan investigasi kontak TB.
